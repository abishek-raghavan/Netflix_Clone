Netflix-Clone
Overview
Netflix-Clone is a web application that mimics the user interface and functionality of Netflix but with a unique twist: instead of playing full movies, it plays trailers of the movies listed on Netflix. This project is built using ReactJS and leverages the MovieDB API to fetch and display movie data and trailers.

Features
Movie Trailers: Browse through a selection of movies and watch their trailers directly within the app.
Netflix-Like Interface: Enjoy a user interface that closely resembles the look and feel of Netflix, offering a familiar and intuitive browsing experience.
Dynamic Movie Lists: Fetches the latest movies, trending titles, and top-rated selections using the MovieDB API.
Responsive Design: Optimized for both desktop and mobile devices, ensuring a seamless experience across different screen sizes.
Technologies Used
ReactJS: The front-end framework used to build the user interface.
MovieDB API: Used to fetch movie data, including titles, descriptions, images, and trailers.
CSS: For styling the application and ensuring it looks and feels like Netflix.
